## 0. 数据模型 ✅（锚点：model/TrainingModel.ets + model/DataStore.ets）

- **Student**：`id`(number) / `name` / `className` / `totalSessions` / `monthlySessions`(兼容快照，展示不消费) / `payType`('monthly'月结｜'semester'学期) / `totalHours` / `usedHours` / `remainingHours`
- **CheckInRecord**：`date`('YYYY-MM-DD') / `studentId` / `studentName` / `timestamp` / `hours`(**默认 1**，历史数据缺省按 1 计，v4.9.2)
- **ClassInfo**：`id`(UUID) / `name` / `students[]` / `records[]` / `createdAt` / `updatedAt` / `studentIdCounter`
- **持久化形态（安卓为行为兼容基准）**：全部班级序列化为**单个 JSON 数组**存 KV 单键（DataStore KEY_CLASSES='classes'，preferences train_checkin_v4）；装载时重建实例并修重复 id（v29.15）。安卓对应实现：sqflite 单表 JSON 文档或同构关系表，**导出格式必须与鸿蒙一致**
