## 3. 编码纪律（从鸿蒙线血泪史转译）

1. **await 落盘**：所有写库操作必须 await 完成才算成功；失败 toast + 保留内存态，成功前不清脏标记（P1-6 教训）。
2. **启动链零阻塞**：任何非关键路径 IO 不得阻塞主启动链；必须有超时兜底（v29.15 教训）。
3. **学生 ID 单调递增**：ID 分配器持久化，杀进程/导入/删除后不得回退复用（v29.14 教训）。
4. **单解析器**：导入导出 CSV/Excel 只允许一套解析逻辑（P2 口径分裂教训）。
5. **导入不覆写**：导入"更新现有学生"不得清零月结学生 usedHours；导入前自动快照备份。
6. **删除连带**：删除学生必须连带清除其打卡记录（v1.1.0 行为）。
7. **版本标记对质**：开发期在「我的」页显示版本串（如 `android-dev M1`），验证「模拟器看到 = 已实装」。
8. **模拟器验证铁律**：改动必须模拟器验证通过才报告完成；截图取证，不口头宣称。
9. **三主题对齐**：暗夜葡萄（默认深色）/ 奶油纸面（浅色）/ 跟随系统；玻璃质感降级实色（M1 出对比页由蔡老师拍板）。
10. **禁自创**：设计稿（V9 现行界面）有的照做，没有的一律不做；加任何区块前先问蔡老师。
